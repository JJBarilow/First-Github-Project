Cybersecurity Data Science App

Project Overview
This project is a Data Science application built using Python and Dash. It visualizes and analyzes real-world cybersecurity datasets to provide insights into incident categories, resolution statuses, and compliance metrics. The app demonstrates how interactive dashboards can be used to explore complex data effectively.

Repository Contents
- **Capstone.py**: The main Python script that launches the Dash app. It loads the CSV data, processes it, and creates interactive visualizations.
- **CSV files**: Datasets used by the app, containing cybersecurity incident data, vulnerability information, and compliance details.
- **README.md**: This file, providing an overview of the project.

To run the app locally, follow these steps:

Clone the Repository
Download this project by clicking the green "Code" button and selecting "Download ZIP", or by using Git:
git clone https://github.com/your-username/your-repo-name.git
Then navigate to the project folder:
cd your-repo-name

Install Required Python Packages
Ensure you have Python 3.7 or newer installed.
Install the required libraries with:
pip install dash pandas plotly

Run the Application
Make sure all .csv files are in the same directory as Capstone.py. Then, run the app:
python Capstone.py
Once the server starts, your browser will open automatically or you can manually navigate to:
http://127.0.0.1:8050/
