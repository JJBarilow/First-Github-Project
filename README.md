Cybersecurity Data Science App

Project Overview
This project is a Data Science application built using Python and Dash. It visualizes and analyzes real-world cybersecurity datasets to provide insights into incident categories, resolution statuses, and compliance metrics. The app demonstrates how interactive dashboards can be used to explore complex data effectively.

Repository Contents
- **Capstone.py**: The main Python script that launches the Dash app. It loads the CSV data, processes it, and creates interactive visualizations.
- **CSV files**: Datasets used by the app, containing cybersecurity incident data, vulnerability information, and compliance details.
- **README.md**: This file, providing an overview
